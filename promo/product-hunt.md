# Product Hunt Draft

## Name

HelloPlanet

## Tagline

Live Earth and space wallpapers for Windows

## Description

HelloPlanet is a free Windows tray app that automatically refreshes your desktop wallpaper with live Earth and space imagery. It supports global GOES imagery, Asia-Pacific Himawari 2K/4K satellite tiles, NASA APOD, SDO Sun images, and Mars rover photos. It runs quietly in the system tray, has Chinese/English menus, and lets you choose refresh intervals from 5 minutes to 1 hour.

## Maker Comment

I built HelloPlanet because I wanted my desktop to feel connected to the planet instead of being a static image. The fun part was stitching Himawari tiles into 2K/4K Asia-Pacific wallpapers and keeping the app quiet: no default windows, just a tray icon with the last update time.

It is a small Windows utility, free to use, and the source plus exe are on Gitee for now.
