# SourceForge Draft

## Project Name

HelloPlanet

## Short Description

Live Earth and space wallpapers for Windows.

## Description

HelloPlanet is a free Windows tray utility that automatically updates your desktop wallpaper using public Earth and space imagery.

Features:

- Global Earth imagery from GOES
- Asia-Pacific Himawari 2K and 4K satellite wallpaper modes
- NASA APOD astronomy images
- SDO Sun images
- Mars rover photos
- Configurable refresh intervals: 5 minutes, 30 minutes, 1 hour
- Chinese and English tray menus
- Quiet tray-only startup with optional log window
